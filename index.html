Substitution Cipher

❮ ❯

This is a project I did a while back while back. I was told it was a good way to be introduced to programming in C#. Basically how it works is you type a word. In a class labeled cipher I add variables one for the original message type and the another for the Substitution. Then in a instance of that class I assign them a letter using a string and assigne each letter it's replacement. The program looks for the letter with the same index value and subsitutes it with the click of a button. I liked this assignment because I felt like I was getting good at coding.

Cummulative Verse Song

❮ ❯

Another one of my first assignments. The learning objective here was to create code that placed things in places they belong without hardcoding and accurately. The program looks for which day is being talked about in the song and prints the corresponding items. Then it proceeds to the next day adds the items already sang and prints the items corresponding with the incremented number of the day. This assignment was a good exercise to understand what debuging is because it's easy to spot when you did something wrong and the fact that everything is essentially labeled in numerical order makes it easy to go back and fix where you messed up.
